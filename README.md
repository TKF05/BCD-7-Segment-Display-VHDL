## BCD 7-Segment-Display Controller

My first VHDL project, for displaying a four-digit number on a multiplexed seven-segment display.

The design takes in four Binary Coded Decimal (BCD) digits, decodes the inputs, and displays to the seven-segment display. 

## Features

 - BCD to seven-segment display decoding
 - Display multiplexing
 - Asynchronous reset 
 - Synchronized and Debounced input 


## Hardware

 - Digilent Basys-3 FPGA 

## Tools

 - AMD/Xilinx Vivado
 - VHDL
